# Quickstart: Grammarian Feature

This document provides a quickstart guide for the "Grammarian" feature.

## Running the Feature

1.  Ensure the Next.js development server is running (`npm run dev`).
2.  Navigate to `http://localhost:3000/grammarian` in your web browser.

## Using the Feature

1.  **Set the Word of the Day**: At the beginning of the meeting, input the Word of the Day, its meaning, and an example sentence.
2.  **Add Speakers**: Add the names of the speakers for the session.
3.  **Record Observations**: As each person speaks, you can:
    -   Record any improper grammatical uses and provide suggestions.
    -   Note any outstanding words, quotes, or phrases.
    -   Mark off when a speaker uses the Word of the Day.
4.  **Generate Report**: At the end of the meeting, the report will be displayed, summarizing all the observations you've made.
